# Security Policy

## Supported Versions

Only the latest version of this software is supported. Security exploits which cannot be replicated on the latest version will be rejected.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| 0.9.X   | :x:                |


## Reporting a Vulnerability

[Private security reporting](https://goonfleet.com/index.php/topic/381527-impgsf-responsible-disclosure-policy/) is enabled for this project. Please make use of it when reporting security vulnerabilities/exploits.

When submitting a security exploit, please include details about the environment the exploit occurs in, details about the nature of the exploit and how it works, a complete PoC as well as a CVSS assessmment to ensure your exploit can be replicated.
AI Slop vulnerability findings will not be accepted. AI code vulnerability scanners are prone to false positives and create PoCs with unrealistic enviromental requirements.
Please embargo/refrain from disclosing your exploit for at least 60 days to give me time to resolve the vulnerability.
